# Task Skills

Скилл для AI-агентов: превращает размытую идею в конкретную задачу с планом выполнения.

## Установка

```
npx skills add expremiental/task-skills
```

Или через агента:

```
Установи скилл: npx skills add expremiental/task-skills -g -y
```

## Что делает

Когда говоришь `/task` или описываешь идею — агент проводит через 5 шагов:

1. **Идея** — пересказывает что понял, уточняет
2. **Результат** — что на выходе, какие данные, как проверить
3. **Реальность** — что может сделать напрямую, через код, или с твоей помощью
4. **Задача** — переформулирует с учётом реальности
5. **План** — конкретные шаги, начинает с первого

## Для кого

Для всех, кто работает с AI-агентами и хочет получать предсказуемый результат вместо «сделай что-нибудь».
