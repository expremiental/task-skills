# Task Skills

Скилл для AI-агентов: превращает размытую идею в конкретную задачу с планом выполнения. Агент сам ведёт по процессу — уточняет, проверяет возможности, предлагает реалистичный план.

## Установка

### Через агента (рекомендуется)

Скопируй это в чат с агентом (Claude Code, Codex, Cursor):

```
Установи скилл: npx skills add expremiental/task-skills -g -y
```

### Вручную

```bash
npx skills add expremiental/task-skills
```

## Что делает

Когда говоришь `/task` или описываешь идею — агент проводит через 5 шагов:

1. **Идея** — пересказывает что понял, уточняет
2. **Результат** — что на выходе, какие данные, как проверить
3. **Реальность** — что может сделать напрямую, через код, или с твоей помощью
4. **Задача** — переформулирует с учётом реальности
5. **План** — конкретные шаги, начинает с первого

```
> хочу собрать контакты из моих телеграм-групп в таблицу
> нужен контент-план для канала на месяц
> хочу автоматически собирать отзывы с сайтов конкурентов
> сделай рассылку по списку контактов из гугл-таблицы
```

## Поддерживаемые агенты

- Claude Code (CLI и VSCode extension)
- Codex (CLI и VSCode extension)
- Cursor (через Claude Code extension)

## Требования

- Node.js (для `npx skills`)
